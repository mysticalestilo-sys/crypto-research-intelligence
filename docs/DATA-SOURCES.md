# Data Sources

## Initial adapters
- Binance: market and derivatives data
- CoinMarketCap: market, asset and supplementary market data
- CoinGecko: market, asset and historical data

## Future adapter families
- On-chain analytics
- Liquidation/position intelligence
- Smart-money / whale feeds
- Social/KOL data
- Fundamental/revenue/fee sources

Every normalized observation should retain provenance: source, endpoint/metric, observed timestamp, ingestion timestamp, freshness, and quality status.
